# Typed-channel descriptor artifact

Status: SemIR, concrete-specialization, and target-local lifecycle closure
(2026-09-02).

`SemTypedChannelDescriptor` is the session-local record attached to a concrete
SemIR specialization. It keeps local `FunctionRefId` handles only for the
current lowering and records stable payload, layout, lifecycle, capability, and
runtime-epoch fingerprints for publication.

`ConcreteTypedChannelDescriptor` is the target-independent persisted form. It
is encoded in concrete specialization component version 50 beside the
specialized body. Decode and verification reject borrowed/reference payloads,
missing fingerprints, non-transferable payloads, invalid lifecycle targets,
unknown runtime epochs, and malformed callback identities. Callback addresses
and session-local IDs never enter the artifact.

Descriptors are now generated by scanning verified typed transitions before
specific artifact publication. LLVM resolves each descriptor to private
move/drop thunks through the existing nominal lifecycle lowering and emits the
runtime v1 descriptor layout; callback addresses remain target-local.

The descriptor is deliberately independent from the existing byte-channel
CFDL artifact and Component ABI-1. Source `Channel<T>` operations are lowered
only after a typed descriptor has been generated from a complete nominal
move/drop witness and replayed by the consumer. The public API is
Result-based; no bytewise fallback is permitted.

The ABI-2 projection additionally carries canonical component and operation
identity, lease policy, ownership flags, and a descriptor digest. These facts
are consumed by the LowIR payload operation plan and remain design-gate data;
the published Runtime ABI v1 descriptor is unchanged.
