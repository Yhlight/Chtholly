# Chtholly 1.9.1 Ownership Performance

The 1.9.1 stability wave replaces full-graph fixed-point scans with sparse,
deterministic worklists. Counts below were captured on the same Windows x64
workspace before and after the refactor. Wall time is reported separately and
is not a correctness gate. Work-item rows are cold dependency-graph totals,
including source units required by each root package.

| Case | Metric | 1.9 scan baseline | 1.9.1 worklist |
| --- | --- | ---: | ---: |
| 1.9 smoke | provenance work-items | 8,291 | 3,844 |
| 1.9 smoke | postcondition work-items | 4,863,253 | 2,715 |
| 1.9 smoke | SCC function evaluations | 84 | 66 |
| 1.9 smoke | postcondition widenings | 12 | 0 |
| 1.9 smoke | loan-flow plus liveness work-items | 18,677 | 3,064 |
| 1.9 smoke | unique widened loan regions | not measured | 2 |
| telemetry | provenance work-items | 3,425 | 1,836 |
| telemetry | postcondition work-items | 2,423,713 | 1,507 |
| telemetry | SCC function evaluations | 49 | 49 |
| telemetry | postcondition widenings | 6 | 0 |
| telemetry | loan-flow plus liveness work-items | 2,134 | 1,429 |
| telemetry | unique widened loan regions | not measured | 0 |

The committed structural gate requires ownership work below 40% of the scan
baseline, worklist evaluations below 32 times graph size, and zero widening for
callable analysis in both cases. PlaceState widening is conservative, counted,
and structurally bounded. Three telemetry builds on the development host
produced normal cold/warm medians of about 731/579 ms and RelWithDebInfo MSVC
ASan cold/warm medians of about 4.23/3.77 seconds. Both warm modes reused 10 of
11 units, and every reused unit reported zero analysis work.

The ASan compiler uses the normal build's target resource directory so its
instrumented host runtime archive is not linked into the generated user
program. The compiler process remains ASan-instrumented. Reproduce the report
with:

```powershell
.\scripts\measure-ownership-performance.ps1 `
  -Compiler .\build-ninja\tools\chthollyc\chthollyc.exe `
  -AsanCompiler .\build-asan\tools\chthollyc\chthollyc.exe
```
