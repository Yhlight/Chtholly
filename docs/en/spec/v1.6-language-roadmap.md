# Chtholly 1.6 Language Roadmap

Chtholly 1.6 freezes the first standard iteration ecosystem on top of the 1.5
`std::iter::Iterator` protocol. It adds library entities, generic artifact
support, and dynamic-index lowering, but no new source grammar.

## Standard Iteration Ecosystem

The `std::iter::adapters` module declares:

```cns
pub trait Predicate<Args> {
  fn test(self: const Self&, args: Args): bool;
}

pub fn range(start: i32, end: i32): Range;
pub fn from_slice<T>(view: slice<T>): SliceIterator<T>;
pub fn take<I>(iterator: I, count: usize): Take<I>
    where I: std::iter::Iterator;
pub fn map<I, F>(iterator: I, function: F): Map<I, F>
    where I: std::iter::Iterator,
          F: std::callable::Invoke<(I::Item,)>;
pub fn filter<I, P>(iterator: I, predicate: P): Filter<I, P>
    where I: std::iter::Iterator,
          P: Predicate<(I::Item,)>;
```

`range` is an ascending half-open `i32` range `[start, end)`. If `start >= end`
it is empty. There is no range literal, descending mode, step parameter, or
implicit integer conversion.

Arrays and slices enter the protocol explicitly through `from_slice`. The
canonical array form is `from_slice(array[..])`; there is no implicit
`Iterable`, container conversion, or `.iter()` language hook. `SliceIterator<T>`
yields `const T&`, retains the source borrow through its continuation, and uses
the runtime index when borrowing an element.

`take` yields at most `count` Items and never advances its input when count is
zero. `map` invokes a read-only `Invoke` callable once for each yielded Item.
`filter` invokes a read-only `Predicate`; it copies the Item for the predicate
and returns the original Item when accepted. A non-copyable Item is therefore
rejected by the ordinary stable copy-unavailable diagnostic.

Adapters own their iterator and callable values and return the exact adapter as
their continuation. Read-only closures are the frozen callable evidence.
Callable values that retain an external borrow, including ordinary bound-method
environments, remain subject to the existing carrier escape proof; 1.6 adds no
loan exemption or staged continuation capability.

Composition uses nested free-function calls or named intermediate values.
Pipeline syntax, extension methods, implicit iteration, enumerate, collection,
and mutable callable adapters are outside 1.6.

## Ownership And Cleanup

All constructors consume owned iterator/callable arguments through ordinary
`move`. Adapter `next` functions consume `Self`, move the input continuation
back into the returned adapter, and preserve ordinary reverse-order cleanup on
Done, Item, rejection, break, continue, and return paths. `filter` keeps the
predicate across rejected Items without copying the predicate.

The existing `foreach` grammar and lowering are unchanged. Owned Items move
from `IterationStep`; references are copied with their verified provenance.

## Artifacts And Lowering

Public generic templates and concrete specialization nodes preserve every local
type together with its mutable/temporary/uninitialized flags. Dependent
associated-type substitutions are applied before nested interface calls are
specialized. Failed child-block cloning propagates as a specialization failure
instead of leaving malformed SemIR.

Generic template opcodes append `MemberAccess` and `Index`. LowIR appends
`DynamicIndexBorrow` so a dynamic array element borrow carries its runtime
index; slice indexing returns the underlying element address rather than a
temporary or a fixed element.

The semantic artifact epoch is 12, standard-library compiler contract is 10,
API epoch is 14, and standard-library compatibility epoch is 7. Package state
format is `CHNXTPK67` version 64; concrete specialization components use format
43. These boundaries fail closed on stale artifacts.
